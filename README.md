## About this entry

The line is a patch note for human sleep, written exactly the way a
real changelog would write it. Version 2.1 fixes the bug where eight
hours of sleep still left the user tired, sleep now actually works,
and the only side effect is that mornings remain terrible. The joke
is that the fix is real and nothing gets better, because mornings
were never the bug in the first place. The changelog voice is what
sells it: the version number, the fixed bug, and the deadpan side
effect all sit plausibly in a release note, and the whole thing fits
in a single line inside the one hundred and sixty character cap. The
program holds the line, checks it against that cap, and writes it to
/output/entry.txt exactly as the bounty requires.
